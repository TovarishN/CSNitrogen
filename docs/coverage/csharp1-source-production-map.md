Context policies: attribute argument order and non-assignment roots; declaration accessor cardinality; static constructor forms; struct declaration/version restrictions; statement-expression root category; direct-local stackalloc placement; Unicode keyword/token separation; static-class introduction in C# 2 and auto-property introduction in C# 3 (unsupported after introduction until modules exist). Parameter order, interface bodies, using placement and unsafe membership are constrained by grammar. Binding-dependent rules are excluded.

Completion gaps: independent per-production shape and negative-context closure; review imported C# 1 release-history entries; frozen historical Unicode/reference policy; larger independent external corpus. Compiler intrinsic expressions are excluded from the standard baseline. A small passing corpus is not a completion gate.
