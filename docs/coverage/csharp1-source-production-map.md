Context policies: attribute argument order and non-assignment roots; declaration accessor cardinality; static constructor forms; struct declaration/version restrictions; statement-expression root category; immediate array-creation element-target exclusion (CSN2005); direct-local stackalloc placement; Unicode keyword/token separation and identifier categories (shared historical/current grammar superset plus selected policy); static-class introduction in C# 2 and auto-property introduction in C# 3 (unsupported after introduction until modules exist). Parameter order, interface bodies, using placement and unsafe membership are constrained by grammar. Binding-dependent rules are excluded.

Completion gaps: independent per-production shape and negative-context closure; review imported C# 1 release-history entries; historical Unicode freezes for profiles after CSharp1; larger independent external corpus. Compiler intrinsic expressions are excluded from the standard baseline. A small passing corpus is not a completion gate.

CSharp1 pins Unicode 3.0 BMP categories across parsing and preprocessing; other profiles use the current .NET 10 categories. Historical-only active whitespace is normalized to equal-length space before the shared token grammar consumes it, preserving original source and offsets. See the historical Unicode evidence report for independent exhaustive category observations and the limits on semantic normalization/supplementary characters.
