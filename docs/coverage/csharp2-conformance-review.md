# CSharp2 source conformance disposition

Primary: ECMA-334 fourth edition (June 2006), SHA256 de596c178a4a80a8d86e91877544025822ec0749d8c04ecca25af60c75937652. Physical PDF pages465–494 supply 409 Annex A occurrences; normative prose controls the source interpretation. The original candidate omitted twelve one-of headings. The pinned extractor now records those occurrences, bodies, source bounds and Annex section. Duplicate and unsafe-extension identities remain independent.

This admission uses the same normalized syntax/policy boundary as the reviewed CSharp1 profile. Completeness covers generated syntax, declared context policies, original UTF16 offsets and source-backed historical discrepancies. It does not assert that every accepted program compiles, binds, type-checks, lowers or executes. An accepted syntax tree can contain semantically invalid types, values or declarations.

## Audit dispositions

The four retained source audit reports are inspection records. Their proposed failures were subsequently executed by the closure regression suites; these reports alone are not execution evidence. The crosswalk links every exact occurrence to its source-domain report, normative clauses, actual Nitrogen AST owners and finite witness groups. Shared list/wrapper and precedence owners normalize several source categories; a mapping does not imply a one-to-one grammar spelling.

- Lexical and preprocessing: Unicode4 data is pinned independently of current .NET categories, including supplementary scalar identifiers, escapes, formatting and historical spaces. CSharp2 has its own trivia and global-target module. Escaped initial underscore and post-Unicode4 letters are rejected. Contextual identifiers accept @, escapes and formatting. Final Control-Z, directive separation, escaped conditional symbols and inactive directive validation follow the historical source. Original source lengths/offsets remain unchanged.
- Expressions/types: generic arguments use every §9.2.3 follower, nullable/coalescing precedence and conditional seams have selected-factory shape witnesses. Single-segment alias type casts are definite; dotted aliases retain the expression/follower ambiguity. A qualified alias member alone is not a historical primary expression; the previous A::F<int>(x) positive was retained as a negative witness and replaced by A::T.F<int>(x). Anonymous/default/unbound typeof and unsafe generic forms retain generated typed owners.
- Statements/iterators: §15.14 placement and §26.1 ref/out, ordinary-return and explicit unsafe-block restrictions are checked from syntax in CSharp2. Anonymous function boundaries reset ownership. Nested unrelated catches do not prohibit a yield elsewhere. Yield remains an identifier outside the contextual form. Binding of enumerable return interfaces, yield conversions, lowering, execution and capture are excluded.
- Declarations/attributes: fourth-edition attribute arguments use expression, including assignment shapes; alias-qualified attribute names are supported. Unknown targets warn, typevar is recognized, and global target normalization uses Unicode4. Unknown targets before a namespace/recognized global sequence or EOF are global; before a type they retain ordinary attribute ownership. Override permits a single marked accessor; explicit-interface accessors and indexer ref/out restrictions are enforced. Constraint source shapes and struct/new incompatibility are checked. Fixed-buffer primitive spellings, struct owner, instance declaration and explicit vector count follow the pinned Microsoft VS2005 supplement p959.

## Explicit historical discrepancies and boundaries

The source's §9.3.1/Annex new-line prints U+2085 for NEL, conflicting with §9.3.2 and the Unicode character name; the implementation selects U+0085. Modern Roslyn is secondary evidence: its current Unicode categories, escaped contextual spellings, attribute-expression restrictions, alias expression recovery and current directive effects cannot override the pinned source. Fourth-edition #line digits are unbounded (including zero); exact BigInteger mappings retain them. Unknown #line identifiers warn and preserve previous mappings; hidden and module are declared implementation-defined compatibility choices. #pragma remains opaque warning-bearing compiler information with no compiler effects.

The inherited declaration/statement semantic exclusions remain explicit: modifier compatibility and finite modifier-set over-approximations; accessibility ordering/applicability; declaration-space and duplicate-name/constraint resolution; class/interface/type-parameter denotation; enum underlying-type and params/indexer type legality; unsafe legality/addressability/handler restrictions; break/continue/goto/return/throw target legality; constant, type, lvalue and conversion validity; reachability/definite assignment; binding, overloads, captures, lowering and execution. No source row claims those semantic operations. Duplicate where names require declaration identity analysis and remain excluded; struct/new incompatibility and top-level constraint syntax shapes require no binding and are enforced. The fixed-buffer element spelling set is enforced, while unsafe-context/type alias legality remains in the inherited semantic boundary.

CSharp3–14 and custom composition remain partial. They inherit additive grammar capabilities, but CSharp2's historical Unicode/directive/iterator policy is selected only for its reviewed profile. The user-approved type-operand revision adds an operand wrapper to CSharp1 trees and changes the generated is/as Type property types; the underlying TypeReference child and original offsets remain. See csharp2-type-operand-migration.md. CSharp1 retains its independent source gate and Unicode3 policy; generated lexical supersets are filtered by the selected profile.

## Admission evidence

The conformance ledger records the exact generated-factory membership/root, actual authored AST identities, reviewed parser/preprocessor/grammar source hashes, primary and Unicode pins, source index/crosswalk hashes and witness methods. Runtime admission validates that reviewed snapshot and the actual compiled factory. Independent oracle tests parse the real .ngr ASTs and resolve every crosswalk owner/witness.
