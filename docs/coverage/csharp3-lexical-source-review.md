## Source input, trivia and tokens

§2.3 requires source input normalization of terminal Control-Z and a final line terminator. SourceLines and ConditionalPreprocessor preserve original UTF16 coordinates and use a virtual final line without appending source characters. CSharpTrivia.SkipUnicode4 handles CR, LF, CRLF, NEL, LS and PS. Comments do not nest, delimiter-like text inside literals is not a comment, and newline terminates a single-line comment. The rearranged delimited-comment grammar uses the same first closing delimiter language as the existing trivia scanner. Unicode4 Zs plus tab, vertical tab and form feed are whitespace. Source2's printed NEL typo is absent here: main/Appendix both name U+0085.

The Lexical module supplies the raw generated token language; selected profile policy filters the generated Unicode superset. Adjacent word leaves cannot split a historical Unicode4 identifier into keyword/contextual token plus name, including supplementary scalar and escape boundaries. `=>` is the third-version punctuation addition; lambda signature/body witnesses exercise it in the actual factory. Right-shift components are contiguous (`>|>`/`>|>=` denote no intervening character), independently of trivia between nested generic closers.

## Identifiers and literal syntax

§2.4.1–2.4.3/main1232–1269: Unicode escapes are processed in identifiers and character/regular string literals, not into keyword/operator tokens. Raw keyword spelling is reserved; escaped equivalents remain identifiers. Identifier start/part/format and space classes use the user-approved frozen Unicode4 scalar tables, not current host categories. Literal initial underscore is permitted; escaped initial underscore is not among the starting-character alternatives. Raw or escaped supplementary scalars retain their authored UTF16 lengths; isolated surrogates and escapes beyond U+10FFFF are invalid identifiers. Verbatim prefixes, escape decoding and Cf removal determine contextual identity. Non-NFC identifiers are retained without an added diagnostic, the source's permitted implementation-defined behavior. Double-underscore implementation names retain the baseline reserved implementation extension boundary.

§2.4.4: integer syntax is decimal or hexadecimal, with the finite U/L suffix permutations; binary digits and separators belong to later versions. Reals require their stated fractional/exponent/suffix alternatives. Character literals contain one UTF16 character or a permitted escape, including a surrogate code unit; a supplementary scalar escape requires a string surrogate pair and is not a character literal. Regular strings process escapes once; verbatim strings preserve backslashes and double quotes by quote escaping. Raw NEL is a line terminator in regular strings/characters; verbatim strings may contain it. Numeric value ranges, rounding, constant-expression binding and conversions remain excluded semantic operations. Literal escape spelling/bounds and malformed token neighbors remain syntax obligations.

## Preprocessing

§2.5: directives occupy the first non-whitespace position of a physical line. Names/mandatory arguments require their source separators, comments are permitted only where the production admits them, and inactive regions still require valid directive structure/forms. Conditional expression precedence, parentheses, symbols, declaration-before-token restriction, matching if/elif/else/endif and region nesting are checked without compiling disabled text. The third-version conditional-symbol production is identifier-or-keyword except raw true/false: `@` prefixes are excluded here, while escaped or format-normalized boolean spellings are symbol names. Keywords such as class may be symbols. All six source line-terminator forms split comments and directives without changing offsets.

Diagnostic message payload is arbitrary authored text; quotes or comment delimiters within it do not become tokens. Active error directives produce errors, warning directives produce warnings, and inactive errors do not fire. Regions have no language semantics but cannot cross conditional sections. `#line` admits exact decimal digits or raw default/hidden and optional nonempty quoted filename; escapes are not filename processing. Exact BigInteger mapping retains all source digit strings, including zero, independently of current compiler/PDB limits. An inactive valid mapping has no effect. Source2's implementation-defined identifier alternative is not inherited.

§2.5.8/main1482–1494 makes pragma information optional compiler context and describes unknown directives producing warnings rather than compilation errors. The declared normalized policy preserves the entire payload with an explicit implementation-information warning, including warning disable/restore syntax; it does not suppress compiler warnings or implement compiler effects. The four pragma-body/action/list source categories are owned by this opaque policy, not claimed as generated AST nodes or compiler operations. This retains the reviewed baseline normalization while recording CSharp3's printed structured productions. Unknown preprocessing directive names outside pragma remain errors.
