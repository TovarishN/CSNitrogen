# CSharp5 context measurement

Build Release with SDK10.0.100. Run the built DLL while this task's builds/tests are idle. The harness checks every input, warms1000 operations, and retains seven timing/thread-allocation rounds. Raw CSharp4 isolates grammar cost; policy cases include preprocessing and source checks. Incremental edits change only a class-name character. Active CSharp5 is candidate-only; source admission remains separate.

For a comparison, set `CSNitrogenBenchmarkRoot` to the earlier CSNitrogen source and use the same `NitrogenRoot` for both builds. Copy each complete build output to a separate directory before building the other candidate. Pass `--baseline` when running the earlier source, which has no async implementation. This is an exploratory measurement, not an editor-latency, retained-memory or conformance claim; retain samples, revisions and artifact hashes.
